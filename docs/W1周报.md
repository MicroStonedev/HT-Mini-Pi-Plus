## 四、踩坑记录（误差追踪表 · 第一批）

| # | 症状 | 根因 | 修法 |
|---|---|---|---|
| 1 | SSH 连不上/"卡在初始化" | IP 抄错一位 + 用户名应为 ubuntu；公网 IP 关机后回收复用 | 以控制台实时 IP 为准 |
| 2 | `pip install isaaclab[sim]` 警告无此附加项 | 2.1.0 无 sim extra | 拆成 isaaclab + isaacsim[all] 分装 |
| 3 | flatdict 构建失败 | setuptools 84 移除 pkg_resources | 降级 setuptools<81 + `--no-build-isolation` |
| 4 | 冒烟测试 libGLU.so.1 缺失 | 镜像缺图形库 | `apt install libglu1-mesa` 等 |
| 5 | `No module named isaaclab.envs` | **pip 版 isaaclab 是空壳脚手架** | IsaacLab v2.1.0 源码安装（5 子包 + apps/） |
| 6 | Kit "extension untrusted" 启动失败 | isaaclab_tasks/mimic 等扩展未装 | 逐个 `pip install -e source/*` |
| 7 | `cannot import quat_apply_inverse` | API 版本改名 | 全局替换为 quat_rotate_inverse |
| 8 | `mdp.randomize_rigid_body_com 不存在` | 仓库与 isaaclab 2.1.0 版本缺口 | 自写 no-op 垫片（签名对齐参数校验） |
| 9 | 回放卡在 EULA 提问 | tmux 内无交互输入 | `ACCEPT_EULA=Y` 环境变量 |
| 10 | pip 下载大文件反复涓流卡死 | 平台 NAT 掐持续传输 | 自愈循环 + 防卡看门狗 + 断点缓存 |

另：云端 GitHub 封锁 → 本地打包中转；镜像开新机 authorized_keys 被重置 → 重推公钥。
