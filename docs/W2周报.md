## 三、消融实验（B+C 组，各 200s × 3 次扰动注入）

**B 组·推力扰动**（冲量 = 力 × 0.5s ÷ 整机质量 10.98kg，实测自动校准）

| 推力 | 击倒/3 | 存活率 |
|---|---|---|
| 40 N | 0/3 | 100% |
| 80 N | 3/3（推后即倒） | 0% |
| 120 N | 3/3 | 0% |

→ **自训策略抗扰边界 40–80 N**（官方 80–120 N；自训训练量 37.5%，边界下移一档符合预期）

**C 组·地面摩擦**

| 摩擦 | 跌倒 | 奖励 |
|---|---|---|
| 0.4 / 0.8 / 1.2 | **全部零跌倒** | 0.0883 / 0.0861 / 0.0828 |

→ 摩擦鲁棒性完整覆盖，低摩擦下奖励最高
